Mood Report Program Design

Project Overview

This project is an assignment that I did while I was taking Structured problem Solving course, it focuses on designing the logic for a Mood Report program. This program first accepts a student ID and a mood score, then categorizes the mood, and calculates summary information including the average, highest, and lowest mood scores. To finalize the project, I developed an input/output design, flowchart, hierarchical chart, Humanual and program level walkthrough, and pseudocode. This project really helped me practice structured problem solving, program logic, and algorithm design.
