Mood Report Program Design

Project Overview 1

This project is an assignment that I completed while taking Structured problem Solving course. It focuses on designing the logic for a Mood Report program. The program first accepts a student ID and a mood score, then categorizes the mood, and calculates summary information including the average, highest, and lowest mood scores. To finalize the project, I developed an input/output design, flowchart, hierarchical chart, Humanual and program level walkthrough, and pseudocode. This project really helped me practice structured problem solving, program logic, and algorithm design.

Date Format Conversion - Leap Year Determination

Project Overview 2

This project focused on designing the first part of a Date Format Conversion program. The program accepts a client number and dates in month/day/year format and determines whether each date occurred during a leap year. It also produces summary information including the number of leap-year dates, the number of non-leap-year dates, the percentage of dates that occurred during leap years, and the most recent leap year. To develop the solution, I completed a problem statement and input/output design, walkthroughs, and a hierarchy chart. This project helped me practice structured problem solving, program logic, testing, and program design.
